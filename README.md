# jogo_de_montar_hardware, desenvolvido pelos e para os alunos excercitare, html, css e javascript

Precisa redimensionar para ajustar a posição do slots
A dificuldade está em ajustar o tamanho da placa para que os slost excaixes com os espaços para encaixar.
Divirta-se tentando sua soluções.
